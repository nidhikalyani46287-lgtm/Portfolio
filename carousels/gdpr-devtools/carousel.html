01Consent

What the cookie
banner taught me.

Try opening DevTools → Network → reload, before touching the banner. Anything that loads before you click "Accept" loaded without consent. It helped me see how §25 TTDSG plays out in practice.

02Transfer

A German server
can still be a
US question.

Something I didn't expect: add the Remote Address column and drop the IP into ip-api.com. A US-owned host can mean an Art. 44 transfer even if the box sits in Frankfurt — the CLOUD Act looks past geography.

03€100 each

The font that
surprised me
most.

Filtering Network by "font" was an eye-opener. If fonts.gstatic.com loads, a visitor's IP goes to Google on load. A Munich court awarded €100 in damages over this in 2022 — and the fix is gentle: host the font locally.
Network — filter: font
fonts.googleapis.com/css200 · US
fonts.gstatic.com/…woff2200 · US
LG München I · 3 O 17493/20 · 20.01.2022
